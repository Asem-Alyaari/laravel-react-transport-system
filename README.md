# 🚌 نظام إدارة وحجوزات النقل البري المتكامل (Full-Stack Intercity Bus Transport & Booking System)

نظام متكامل وشامل لإدارة أسطول حافلات النقل البري بين المدن، المحطات، والرحلات، مع واجهة أمامية تفاعلية حديثة، ونظام حجز مقاعد ديناميكي فوري، وتسعير متعدد المقاطع، وتقارير وإحصائيات مالية وتشغيلية متقدمة.

## 🌟 نظرة عامة

تم تصميم هذا النظام ليكون حلاً متكاملاً لشركات النقل البري وسفريات الحافلات بين المدن، حيث يربط بين:
1. **واجهة الإدارة والموظفين (Admin & Agent Portal)**: للتحكم الكامل في الأسطول، المحطات، جداول الرحلات، السائقين، والاطلاع على كشوفات الركاب (Manifest) وتقارير الإيرادات.
2. **بوابة حجز المسافرين (Passenger Booking Experience)**: للبحث عن الرحلات بين المدن، استعراض خريطة المقاعد التفاعلية وحالتها الحية، اختيار المقاعد وتأكيد الحجز الفوري مع إصدار تذاكر إلكترونية.
3. **خلفية برمجية قوية (Robust RESTful API)**: مبنية على Laravel 12 وفق أفضل الممارسات البرمجية وفصل الاهتمامات (Service Layer, Form Requests, API Resources).

## ✨ المميزات الرئيسية

### 1. 🏢 إدارة المحطات والمسارات (Stations & Routes)
* **المحطات المركزية والفرعية**: إدارة المحطات بإحداثيات GPS جغرافية دقيقة، بيانات الاتصال، وتحديد الحالة (مفعلة/معطلة).
* **المسارات متعددة المحطات (Multi-Stop Routes)**: إمكانية إنشاء مسار بين مدينتين مع تحديد محطات توقف وسيطة ومرتبة تسلسلياً مع احتساب المسافات بالكيلومتر والزمن المقدر.
* **تسعير المقاطع المتعددة (Segment Fares)**: تحديد وحساب أسعار التذاكر بدقة بين أي محطتين على المسار (من محطة الركوب إلى محطة النزول).

### 2. 🚍 إدارة الأسطول وتخطيط المقاعد (Fleet & Seat Layouts)
* **أسطول الحافلات**: تتبع بيانات الحافلات، أرقام اللوحات، الموديل، الصانع، وسنة الصنع، والتجهيزات المتاحة (واي فاي، شواحن، تكييف، شاشات، مرحاض).
* **تخطيط وقوالب المقاعد (Seat Layouts)**:
  * دعم قوالب مقاعد مرنة (حافلات VIP بنظام 2+1، وحافلات عادية واقتصادية 2+2).
  * تصنيف المقاعد حسب موقعها (ممر Aisle، نافذة Window).
  * خريطة مقاعد حية وتفاعلية توضح حالة كل مقعد (متاح، محجوز، أو مقفل مؤقتاً).

### 3. 👨‍✈️ إدارة السائقين (Drivers Management)
* سجل كامل لبيانات السائقين، أرقام الرخص وتواريخ انتهائها، أرقام التواصل، وتعيينهم على الرحلات المجدولة.

### 4. 🎫 جدولة الرحلات والحجز الذكي (Trips & Bookings)
* **جدولة الرحلات**: تحديد تواريخ وأوقات الانطلاق والوصول، وربط الرحلة بالمسار، الحافلة، والسائق.
* **محطات الرحلة المجدولة (Trip Stops)**: حساب المواعيد المقدرة للوصول والانطلاق من كل محطة توقف وسيطة تلقائياً.
* **قفل المقاعد المؤقت (Seat Locking Mechanism)**: حماية لمنع التعارض وحجز المقعد نفسه من أكثر من مستخدم في الوقت نفسه أثناء مرحلة الحجز.
* **حجز متعدد وتذاكر مستقلة**: إمكانية حجز عدة مقاعد لعدة ركاب ضمن حجز واحد مع إصدار تذكرة خاصة ورمز مرجعي فريد لكل مسافر.

### 5. 📊 التقارير ولوحة القيادة (Reports & Analytics)
* **ملخص الأداء (Summary Stats)**: إجمالي الحجوزات، الإيرادات المالية الإجمالية، الرحلات النشطة، ومتوسط معدل إشغال الحافلات.
* **مخطط الإيرادات (Revenue Trends)**: عرض بياني للإيرادات اليومية وتوزيع المبيعات.
* **أداء المسارات (Route Performance)**: تحليل المسارات الأكثر طلباً والأعلى دخلاً.
* **مانيفست الرحلة (Trip Manifest)**: كشف رسمي بأسماء وركاب الرحلة وتذاكرهم ومحطات صعودهم ونزولهم.

## 🛠 هيكلية النظام والتقنيات المستخدمة

### الخلفية (Backend):
* **Laravel 12**: أحدث إصدار من إطار العمل الأقوى للـ PHP.
* **PHP 8.2+**: مع تطبيق ممارسات النوع الصارم `declare(strict_types=1);`.
* **Laravel Sanctum**: لإدارة التوكنز وتأمين استدعاءات الـ API عبر Bearer Tokens.
* **MySQL / MariaDB**: مع هيكل قواعد بيانات مدروس وعلاقات Foreign Keys و Indexes محسنة للأداء.
* **Service-Oriented Architecture**: فصل منطق العمليات (Business Logic) في طبقات خدمات مستقلة.

### الواجهة الأمامية (Frontend - `transport-client`):
* **React 19 & Vite**: أداء فائق السرعة وتجربة مستخدم سلسة وخفيفة (Single Page Application).
* **Tailwind CSS v4**: واجهات عصرية ومتجاوبة بالكامل مع مختلف الشاشات.
* **Lucide React**: أيقونات تفاعلية وواضحة.
* **Axios**: للاتصال السلس مع خادم الـ API والتعامل مع التوكنات وتجديد الجلسة.

## 👥 الأدوار والصلاحيات (RBAC)

يحتوي النظام على نظام صلاحيات متعدد عبر Middleware مخصص:
1. **مدير النظام (`admin`)**: صلاحيات كاملة لإدارة الأسطول، المحطات، المسارات، الرحلات، السائقين، والاطلاع على التقارير المالية والتشغيلية.
2. **موظف الحجز (`agent`)**: استعراض الحافلات والرحلات، تأكيد الحجوزات، إصدار التذاكر للعملاء بالمحطة، واستعراض تقارير الرحلات والمانيفست.
3. **المسافر (`passenger`)**: البحث عن الرحلات بين المدن، استعراض خريطة المقاعد وحالتها، إنشاء الحجوزات واستعراض التذاكر الصادرة.

## 🚀 خطوات التثبيت والإعداد

### 1. إعداد الخلفية (Backend - Laravel)

1. **استنساخ المستودع (Clone Repository)**:
   ```bash
   git clone https://github.com/Asem-Alyaari/laravel-react-transport-system.git
   cd laravel-react-transport-system
   ```

2. **تثبيت حزم الـ PHP عبر Composer**:
   ```bash
   composer install
   ```

3. **إعداد ملف البيئة (`.env`)**:
   ```bash
   copy .env.example .env
   ```
   تأكد من تعديل بيانات الاتصال بقاعدة البيانات في ملف `.env`:
   ```env
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=transport_db
   DB_USERNAME=root
   DB_PASSWORD=
   ```

4. **توليد مفتاح التشفير للتطبيق**:
   ```bash
   php artisan key:generate
   ```

5. **إنشاء الجداول وحقن البيانات التجريبية (Migrations & Seeders)**:
   تأكد من وجود قاعدة بيانات باسم `transport_db` في MySQL، ثم نفّذ:
   ```bash
   php artisan migrate --seed
   ```

6. **تشغيل خادم الـ Backend**:
   ```bash
   php artisan serve
   ```
   يعمل الخادم تلقائياً على الرابط: `http://127.0.0.1:8000`

---

### 2. إعداد الواجهة الأمامية (Frontend - React & Vite)

1. **الدخول إلى مجلد العميل**:
   ```bash
   cd transport-client
   ```

2. **تثبيت حزم الـ Node**:
   ```bash
   npm install
   ```

3. **إعداد ملف بيئة العميل (`.env`)**:
   ```bash
   copy .env.example .env
   ```
   محتوى الملف الافتراضي:
   ```env
   VITE_API_URL=http://localhost:8000/api
   ```

4. **تشغيل خادم التطوير للواجهة**:
   ```bash
   npm run dev
   ```
   ستفتح الواجهة على الرابط: `http://localhost:5173`

## 🔑 بيانات الدخول التجريبية (Seeders)

تم تضمين حسابات تجريبية مسبقاً لاختبار كافة الصلاحيات:

| الدور (Role) | البريد الإلكتروني | كلمة المرور | رقم الهاتف | الصلاحيات المتاحة |
| :--- | :--- | :--- | :--- | :--- |
| **مدير (Admin)** | `admin@transport.sa` | `password` | `0500000001` | تحكم وإدارة شاملة لجميع أقسام النظام والتقارير |
| **موظف (Agent)** | `agent@transport.sa` | `password` | `0500000002` | إدارة الحجوزات والرحلات واستعراض المانيفست |
| **مسافر (Passenger)** | `passenger@transport.sa` | `password` | `0500000003` | البحث عن الرحلات وحجز المقاعد وتتبع الحجز |

## 📡 دليل مسارات الـ API

جميع الاستجابات ترجع بصيغة `JSON`. عند استدعاء المسارات المحمية يجب إرسال الترويسات التالية:
* `Accept: application/json`
* `Authorization: Bearer <YOUR_TOKEN>`

### 🧪 اختبار الاتصال
* `GET /api/test-db` : فحص اتصال التطبيق بقاعدة البيانات.

### 🔐 المصادقة (Authentication)
* `POST /api/auth/register` : تسجيل حساب مسافر جديد.
* `POST /api/auth/login` : تسجيل الدخول واستلام رمز الوصول (Bearer Token).
* `POST /api/auth/logout` : تسجيل الخروج وإلغاء التوكن (يتطلب توكن).
* `GET /api/auth/me` : جلب بيانات المستخدم المسجل حالياً.

### 🏙️ المحطات والمسارات (Stations & Routes)
* `GET /api/stations` : قائمة المحطات النشطة.
* `POST /api/stations` *(Admin)* : إضافة محطة جديدة.
* `PUT /api/stations/{id}` *(Admin)* : تعديل بيانات محطة.
* `DELETE /api/stations/{id}` *(Admin)* : تعطيل/حذف محطة.
* `GET /api/routes` : استعراض كافة المسارات مع محطاتها وتفاصيلها.
* `POST /api/routes` *(Admin)* : إنشاء مسار جديد مع تحديد محطات التوقف.

### 🗺️ البحث وحجز الرحلات (Trips & Bookings)
* `GET /api/trips/search` : البحث عن الرحلات حسب محطة المغادرة والوصول وتاريخ السفر.
* `GET /api/trips/{trip}/seat-map` : جلب خريطة المقاعد التفاعلية وحالة كل مقعد (متاح / محجوز) للمقطع المحدد.
* `POST /api/bookings` : إنشاء حجز جديد وتأكيد المقاعد وإصدار التذاكر.
* `GET /api/bookings/{reference}` : تتبع واستعراض تفاصيل الحجز بالرمز المرجعي.

### 🚌 الأسطول والسائقين (Fleet & Drivers)
* `GET /api/buses` : استعراض أسطول الحافلات.
* `POST /api/buses` *(Admin)* : إضافة حافلة جديدة وتعيين قالب المقاعد لها.
* `GET /api/drivers` : استعراض السائقين.
* `POST /api/drivers` *(Admin)* : إضافة سائق وتحديث بيانات الرخصة.
* `GET /api/seat-layouts` : استعراض قوالب المقاعد (VIP 2+1، عادي 2+2).

### 📈 التقارير والتحليلات (Reports)
* `GET /api/reports/summary` : ملخص شامل (الإيرادات، عدد التذاكر، الرحلات النشطة، نسبة الإشغال).
* `GET /api/reports/revenue-chart` : رسم بياني لتوزيع الإيرادات بحسب الأيام.
* `GET /api/reports/routes-performance` : تحليل أداء المسارات الأكثر إيراداً وحجوزات.
* `GET /api/reports/trip-manifest/{trip}` : كشف ركاب الرحلة الرسمي والتذاكر الصادرة.

## 📁 هيكلية المشروع (Folder Structure)

```text
transport/
├── app/
│   ├── Http/
│   │   ├── Controllers/Api/   # متحكمات الـ API لكل الموارد
│   │   ├── Middleware/        # فلاتر الصلاحيات (RoleMiddleware)
│   │   ├── Requests/          # كلاسات التحقق من صحة المدخلات
│   │   └── Resources/         # تنسيق استجابات الـ JSON
│   ├── Models/                # نماذج Eloquent وقواعد البيانات
│   └── Services/              # طبقة الخدمات (منطق العمليات والأنظمة)
├── config/                    # ملفات إعدادات Laravel
├── database/
│   ├── migrations/            # تهجير الجداول وقواعد البيانات
│   └── seeders/               # البيانات الأولية والتجريبية
├── routes/
│   └── api.php                # مسارات الـ API الرئيسية
├── transport-client/          # تطبيق الواجهة الأمامية (React + Vite)
│   ├── src/
│   │   ├── components/        # مكونات الواجهة ومودالات الحجز والإدارة
│   │   ├── contexts/          # إدارة حالة تسجيل الدخول والمصادقة
│   │   └── api/               # إعدادات اتصال Axios بالخلفية
│   ├── index.html
│   └── package.json
├── .env.example
├── composer.json
└── README.md
```
